# Agent Guidelines

## Project Overview

This repository contains the fullstack web application for **YFJ Matrimony**, built with **TanStack Start**, **TanStack Router**, **React 19**, **TypeScript**, and **Tailwind CSS v4**.

## Development Rules

- When adding or modifying routes, follow TanStack Router's file-based routing conventions in `src/routes/`.
- Maintain clean TypeScript types and avoid using `any`.
- Keep the design consistent with the design system and Tailwind tokens.

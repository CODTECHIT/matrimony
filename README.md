# YFJ Matrimony

A modern, secure matchmaking and matrimonial platform built for families and individuals.

## Tech Stack

- **Framework**: [TanStack Start](https://tanstack.com/start) (Fullstack React SSR)
- **Routing**: [TanStack Router](https://tanstack.com/router) (Type-safe file-based routing)
- **UI & Design**: [Tailwind CSS v4](https://tailwindcss.com), [Radix UI](https://www.radix-ui.com), Lucide Icons, Sonner
- **State Management**: [TanStack Query](https://tanstack.com/query)
- **Forms & Validation**: React Hook Form, Zod
- **Engine / Bundler**: Vite 8, Nitro 3
- **Language**: TypeScript, React 19

## Getting Started

### Prerequisites

- Node.js 20+ (recommended)
- npm or bun

### Installation

```bash
npm install
```

### Running Locally

Start the Vite development server:

```bash
npm run dev
```

The application will start at `http://localhost:8080/` (or the next available port).

### Building for Production

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Features

- **Profile Discovery**: Filter and search through verified profiles by community, age, location, education, and profession.
- **Matchmaking Dashboard**: Personalized daily recommendations and shortlisted profiles.
- **Direct Messaging**: In-app secure communication between matched members.
- **Interest Requests**: Express interest, accept/decline invites, and follow connection statuses.
- **Subscription Tiers**: Flexible membership plans with premium contact viewing and priority visibility.
- **Admin Control Panel**: Verification workflows, package configuration, and analytics.
